# 金丸法×ECP 資金管理

ボートレースの資金管理ツールです。軍資金を歩兵・騎馬隊・本隊の三部隊に分け（約1:2:4）、各部隊を1:3:9の三段で張ります。

- 軍資金と目標回収率（105%、110% など）を自由に設定
- 日付・レース場・レース・払戻金額で結果を記録
- 投票履歴のCSV保存（ファイル名に日時入り）と、CSV読み込みによる再開
- 合成オッズ計算と買い目配分

## スマートフォンのホーム画面に追加する

- iPhone：Safariで開き、共有ボタン →「ホーム画面に追加」
- Android：Chromeで開き、メニュー →「アプリをインストール」または「ホーム画面に追加」

一度開けば、電波がなくても起動できます。iPhoneでは、ホーム画面のアプリとSafariとで保存データが別々です。Safariで使っていた履歴は、CSVで保存してアプリ側で読み込んでください。

## 保存について

進み具合はブラウザに保存されます。別の端末で続けるときは、CSVで保存してその端末で読み込んでください。

この資金管理は張り方の順番を決めるもので、控除率による期待値のマイナスは変わりません。
